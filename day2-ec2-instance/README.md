# Day 2 – Create an EC2 Instance

## Objective

Learn how to provision an AWS EC2 instance using Terraform.

## Concepts Covered

- Provider
- Resource
- Variables
- Outputs
- Terraform Commands

## Resources Created

- AWS EC2 Instance

## Commands Used

```bash
terraform init
terraform plan
terraform apply
terraform destroy
```

## Learning Outcomes

- Created an EC2 instance using Terraform.
- Used variables to make the configuration reusable.
- Displayed the instance ID and public IP using outputs.
- Practiced the basic Terraform workflow.
